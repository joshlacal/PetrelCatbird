# ``PetrelCatbird``

Catbird-specific AT Protocol lexicon types and helpers, layered on the Petrel core SDK.

## Overview

PetrelCatbird is a Swift package for iOS 18 and macOS 15, part of the Catbird / Petrel family. Source and issues live at [github.com/joshlacal/PetrelCatbird](https://github.com/joshlacal/PetrelCatbird).
